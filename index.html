🗄️ Conciliação e Conexão de Banco de Dados (Supabase PostgreSQL)

Este portal possui suporte nativo para conectar-se ao banco de dados relacional PostgreSQL via Supabase ou rodar em modo Local Persistente (IndexedDB/LocalStorage).

⚙️ Credenciais de Conexão Supabase

📋 Script SQL para Criação das Tabelas no Banco de Dados

Se estiver configurando o Supabase pela primeira vez, acesse o SQL Editor do seu projeto Supabase e execute os comandos abaixo para criar as tabelas necessárias:

-- 1. Tabela de Cidades CREATE TABLE IF NOT EXISTS cidades ( id BIGINT PRIMARY KEY GENERATED ALWAYS AS IDENTITY, rota TEXT NOT NULL, nome TEXT NOT NULL, uf TEXT NOT NULL ); -- 2. Tabela de Clientes CREATE TABLE IF NOT EXISTS clientes ( id BIGINT PRIMARY KEY GENERATED ALWAYS AS IDENTITY, nome TEXT NOT NULL, documento TEXT, cidade TEXT NOT NULL ); -- 3. Tabela de Produtos CREATE TABLE IF NOT EXISTS produtos ( id BIGINT PRIMARY KEY GENERATED ALWAYS AS IDENTITY, nome TEXT NOT NULL, categoria TEXT NOT NULL, peso_saco NUMERIC NOT NULL, preco_unitario NUMERIC DEFAULT 0 ); -- 4. Tabela de Pedidos CREATE TABLE IF NOT EXISTS pedidos ( id BIGINT PRIMARY KEY GENERATED ALWAYS AS IDENTITY, rota TEXT NOT NULL, cidade TEXT NOT NULL, cliente TEXT NOT NULL, forma_pagamento TEXT, valor_total NUMERIC DEFAULT 0, status TEXT NOT NULL, itens JSONB NOT NULL, created_at TIMESTAMP WITH TIME ZONE DEFAULT NOW() );
